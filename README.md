## Вам необходимо создать простое приложение для создания заметок, которое позволит пользователям загружать файлы Markdown, проверять грамматику, сохранять заметки и отображать их в формате HTML. Цель этого проекта — помочь вам научиться обрабатывать загрузку файлов в RESTful API, анализировать и рендерить файлы Markdown с помощью библиотек, а также проверять грамматику заметок.

## Функции
Вам необходимо реализовать следующие функции:

Вы предоставите конечную точку для проверки грамматики заметки.

Вы также предоставите конечную точку для сохранения заметки, которую можно передать в виде текста Markdown.

Предоставьте конечную точку для отображения сохраненных заметок (т. е. загруженных файлов Markdown).

Верните HTML-версию заметки Markdown (визуализированной заметки) через другую конечную точку.
